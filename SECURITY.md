# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability or misconfiguration in this repository, please do not open a public issue.

You can report it directly to the maintainer:
- **GitHub**: [@marwane5h](https://github.com/marwane5h)

## Scope

This repository is designed for educational and portfolio demonstration purposes. All scripts are tested on Ubuntu 24.04 LTS.
